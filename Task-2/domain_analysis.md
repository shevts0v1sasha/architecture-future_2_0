# Разделение на домены

### Медицинский домен
- Описание: Управление медицинскими данными
- Данные: Пациенты, мед карты, персонал, инвентаризация
- Технолонии: Java/Spring, Postgresql, Mongo
- API: REST API для медицинских операций

### Финтех домен
- Описание: Управление финансовыми услугами
- Данные: Клиенты, счета, кредиты, транзакции
- Технологии: Golang, Postgresql, Redis
- API: REST API для финансовых операций

### Аналитический домен
- Описание: Агрегация данных и создание отчетов
- Данные: Агрегированные данные, KPI, метрики
- Технологии: Python/FastApi, ClickHouse, ELK
- API: REST API для аналитики

### ИИ домен
- Описание: Машинное обучение и ИИ-сервисы
- Данные: Модели ML, обучающие данные, предсказания
- Технологии: Python/FastApi, MLflow, Vector DB
- API: REST API для ИИ-сервисов

## Потоки данных между доменами

### Медицинский -> Аналитический
Агрегированная статистика по пациентам

### Финтех -> Аналитический
Финансовые метрики, KPI, отчеты по доходам

### ИИ -> Аналитический
Результаты предсказаний, метрики моделей

### Медицинский -> ИИ
Анонимизированные медицинские данные для обучения

### Финтех -> ИИ
Финансовые транзакции для анализа рисков


## Преимущества разделения на домены

### Независимая разработка
Команды могут работать незасивимо

### Масштабируемость
Каждый домен масштабируется независимо, ресурсы выделяются по потребности домена

### Безопасность
Мед и фин данные изолированы, у каждого домена разные уровни доступа

### Интеграция новых бизнесов
Новые бизнесы добавляются как новые домены, не требуется изменение существующих доменов
